# Architecture Diagrams Directory

This folder holds architectural references, Mermaid sequence maps, and visual specifications for the **GraphQL Mastery Guide**.

## Diagram Index
- `graphql-architecture.mmd` - Spring Boot 3.x GraphQL Request-Response processing pipeline.
- `rest-vs-graphql-lifecycle.mmd` - Network waterfall comparison: REST over-fetching vs GraphQL single payload.
- `resolver-execution-tree.mmd` - AST execution tree traversal and field resolution.
- `n-plus-one-dataloader.mmd` - Inefficient N+1 query loops vs DataLoader batching dispatch.
- `jwt-security-flow.mmd` - HTTP SecurityContext extraction into GraphQL resolver method security.
- `relay-cursor-pagination.mmd` - Edges, Nodes, and PageInfo windowing structure.
- `graphql-subscription-websocket.mmd` - Reactive stream pipeline over WebSocket and Project Reactor Flux.
- `microservices-federation.mmd` - Apollo Federation / Schema Stitching Gateway with Spring Boot subgraphs.
